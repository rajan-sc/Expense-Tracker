# Expense-Tracker

Expense-Tracker is a robust, full-stack personal finance application. It empowers users to easily track daily expenditures, understand where their money goes, and receive AI-driven personalized financial advice. 

The backend is built with Node.js, Express, and Sequelize (MySQL), while the frontend utilizes a lightweight, fast Vanilla Javascript architecture. Premium features like S3 data export and Leaderboards are unlocked via Cashfree payment gateway integration.

## Features

- **User Authentication:** Secure JWT-based signup, login, and email-based password reset.
- **Expense Management:** Add, edit, delete, and view paginated daily expenses.
- **AI Categorization:** Google Gemini AI automatically categorizes expenses based on descriptions.
- **Premium Upgrades:** Live integration with Cashfree for seamless sandbox/production payments.
- **Leaderboard (Premium):** See how your spending ranks against other users.
- **AI Financial Advisor (Premium):** Get personalized spending tips generated by Gemini AI.
- **Data Export (Premium):** Download your entire expense history securely from AWS S3.

## Environment Setup

To run this project, you need to create a `.env` file in the root directory.

```env
PORT=3000

# Database Configuration (MySQL)
SQL_HOST=localhost
SQL_DB=expense_tracker
SQL_USERNAME=root
SQL_PASS=password

# JWT Authentication
TOKEN_SECRET=your_super_secret_jwt_key

# Email Service (Brevo)
BREVO_API_KEY=your_brevo_api_key
BREVO_SENDER_EMAIL=noreply@yourdomain.com
BASE_URL=http://localhost:3000

# Payment Gateway (Cashfree)
CASHFREE_APPID=your_cashfree_app_id
CASHFREE_SECRETKEY=your_cashfree_secret_key

# AI Integration (Google Gemini)
GEMINI_API_KEY=your_gemini_api_key

# Cloud Storage (AWS S3)
AWS_ACCESS_KEY_ID=your_aws_key
AWS_SECRET_ACCESS_KEY=your_aws_secret
AWS_BUCKET_NAME=your_bucket_name
```

## Installation

1. Clone the repository:
   ```bash
   git clone <repository-url>
   cd Expense-Tracker
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Ensure you have a MySQL server running and create the database specified in your `.env`.

4. Start the application:
   ```bash
   npm start
   ```

The server will automatically synchronize the database models and start on `http://localhost:3000`.

## Usage

1. Open your browser and navigate to `http://localhost:3000/`.
2. Click **Sign Up** to create a new account.
3. Once logged in, you will be redirected to the **Expense Dashboard** (`/expense`).
4. Add your daily expenses by entering the amount and description. The AI will categorize it automatically.
5. Click **Upgrade to Premium** to test the payment gateway flow and unlock the Leaderboard, AI Insights, and Data Download features.

## API Overview

For comprehensive documentation covering exact parameters, return types, and application flow, please refer to the `TECHNICAL_DOCUMENTATION.md` file in the project root.

### Public Routes
- `POST /user/signup`: Register a new user.
- `POST /user/login`: Authenticate and receive a JWT.
- `POST /password/forgot-password`: Send a reset link via email.

### Protected Routes (Requires JWT Authorization Header)
- `POST /expense/add-expense`: Add a new expense.
- `GET /expense/get-expenses?page=1&limit=5`: Retrieve paginated expenses.
- `DELETE /expense/delete-expense/:id`: Remove an expense.
- `PUT /expense/edit-expense/:id`: Modify an existing expense.
- `POST /payment/create-payment-order`: Initialize a Cashfree order.
- `POST /payment/verify-payment`: Verify a payment intent.

### Premium Routes (Requires JWT & isPremium status)
- `GET /expense/insights`: Get AI-generated advice.
- `GET /expense/download`: Generate an S3 download link for all data.
- `GET /leaderboard/`: Fetch top spenders.

## Deployment

1. Set up a cloud instance (e.g., AWS EC2, DigitalOcean Droplet) with Node.js and MySQL installed.
2. Clone the repository onto the server.
3. Configure your production `.env` variables (use production DB credentials and Cashfree Production keys).
4. Install `pm2` globally: `npm install -g pm2`.
5. Start the application with PM2 for background execution and crash recovery: `pm2 start app.js --name "expense-tracker"`.
6. Configure Nginx as a reverse proxy to forward port 80/443 traffic to port 3000.
